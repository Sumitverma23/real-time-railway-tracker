# 🚆 Real-Time Railway Tracking System

A real-time train tracking application inspired by **"Where Is My Train"**, built to provide live train status, schedules, and station-wise updates using backend APIs.

## 📌 Project Overview
The **Real-Time Railway Tracking System** helps users track trains in real time without relying on GPS.  
It fetches live train data from APIs and displays accurate train running status, schedules, and station information.
This project demonstrates backend development, REST API integration, and real-world problem solving using Java and Spring Boot.

## ✨ Features

- 🚆 Live train running status
- ⏱️ Train schedule and timing details
- 🛤️ Station-wise arrival and departure updates
- 🔄 Real-time data fetching using APIs
- ⚡ Fast and reliable backend responses

## 🛠️ Tech Stack

- **Java**
- **Spring Boot**
- **RESTful APIs**
- **Maven**
- **Postman** (for API testing)

---

## ⚙️ How It Works

1. User requests train information
2. Backend calls railway-related APIs
3. Real-time data is processed
4. Clean and structured response is returned to the user
